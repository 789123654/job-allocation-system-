# Security Policy

## Supported Versions

This project is pre-release (no tagged releases yet). Only the `main` branch is supported —
security fixes land there directly.

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Instead, use GitHub's private reporting: go to the **Security** tab of this repository →
**Report a vulnerability**. This opens a private advisory visible only to the maintainer, so the
issue isn't disclosed before it's fixed.

You should expect an initial response within a few days.
